# Warehouse
University assignment for Algorithms &amp; Design
A package sorting system written in C, where there are 4 data files holding attributes of a package 
MergeSort and Binary search are used to sort and search through the data. 

Attributes of a package
- containerID
- weight 
- time HH:MM:SS
- ProductCode
- temperature
- CourierId

The code works as follows...

- The original data in printed
- The data is sorted using MergeSort according to time 
- The sorted data is printed
- The program prompts to enter an hour, minute and time, the system tries to locate a package that matches that time
- Every product had arrived in a container, the program prints how many packages were in each container that had arrived as per the data
